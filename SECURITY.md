# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/guided-traffic/dash/security/advisories/new),
not in a public issue. Include what you found, how to reproduce it and the version you tested.

## Supported versions

Dash is before 1.0: only the latest release gets fixes.

## What is already known

The security architecture and every known gap are in [docs/security/](docs/security/README.md).
